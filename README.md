# Levett Carpentry — GitHub Pages POC

A **non-commercial test prototype**, not a live customer website.

Homepage order: **Show Us Your Space → Before & After → Clever Spaces → Meet the Maker → Footer**.

The enquiry form is a **demo only**: entries and selected photos are not uploaded, emailed, or stored.

## Publish on GitHub Pages

1. In this repository, open **Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Choose `main`, then `/(root)`, and select **Save**.
4. After deployment, open `https://danielproduct.github.io/levett-carpentry-poc/`.

**Important:** GitHub Pages is being used to test the site, not to operate a commercial customer-facing business site. Only illustrative content is included. Do not enter real customer details during testing. Later production hosting was planned for Cloudflare Pages.

See `project-notes/` for the scope and test plan. The source is plain HTML, CSS, and JavaScript; no paid tools or build system.
